# Decision D10: Stamp the schema, refuse regressive saves

## Decision

Version the schema and refuse a regressive save.

## Rationale

Four recurrences; re-applying the flag each time treats the symptom.

## Alternatives Considered

- Re-apply the flag each time
- Lock the file
- Accept the loss

## Evidence

- The archived flag was stripped four times by writes from a session holding older code (git log -- .project/goals.yaml)
- A file stamped schema 99 is now refused and left byte-identical, with archived and percent intact (test/storage.test.ts)
- An unstamped file still saves and gains the current stamp (test/storage.test.ts)
