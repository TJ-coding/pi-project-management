# Decision D8: A smoke must fail when nothing loaded

## Decision

Smokes must fail when the extension does not load.

## Rationale

Two of three smokes were meaningless outside one checkout.

## Alternatives Considered

- Trust the working copy only
- Ignore the clone failure as environment noise

## Evidence

- From a clean clone the TUI smoke failed with EIO and the command smoke reported PASS while pi had exited on duplicate tool names (gh repo clone TJ-coding/pi-project-management)
- Reintroducing the bug in a scratch copy now yields 'extension did not load' and exit 1, where before it was exit 0 with PASS (scripts/rpc-commands.mjs)
- All three smokes and 171 tests pass from a clean clone at f298449 (npm run check; npm run smoke:tui; npm run smoke:commands)
