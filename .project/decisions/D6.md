# Decision D6: Redact paths, not names

## Decision

Redact machine-local paths, keep project names.

## Rationale

Absolute paths and a session path are machine noise. Rewriting names would falsify history.

## Alternatives Considered

- Publish as-is (D4's default)
- Redact the project name too

## Evidence

- Four occurrences of /Users/tomoyuki-j and a pi session transcript path, confined to history/events.jsonl, history/history.md and runs/RUN2.yaml (git grep -InE '/Users/tomoyuki-j')
- JSONL and RUN2.yaml still parse after the substitution; 119 tests pass (npm run check)
- The clean clone of the public repo has no local paths (gh repo clone TJ-coding/pi-project-management)
